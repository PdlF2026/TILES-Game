# TILES Game

A 2d one-player game based on a version from my school time. The objective of this repository is to spread the game so that more people know it and can collaborate (suggesting ideas, coding apps and brainstorming the multiplayer mode). 

The tutorial is available when running the game. Part of the code is in spanish since i coded it a long time ago. 

## Apologies

I wanted to upload this game so that everyone can collaborate in its development, since it can be entertaining or even fun! The original code (TESELAS.py) is in Spanish because it was first shown in a sciences school contest.
However, there is an English version, whose code is not that much translated (yet, it is so simple almost anyone can understand it).

## Requirements

No external libraries needed! It runs completely on Python standard libraries: 

* winsound
* random
* os
* time

Each source file is independent, so with only one it is enough to play.
